# Changelog

All notable changes to the released binaries are documented in this file.
The format is based on Keep a Changelog, and this project adheres to Semantic Versioning.

Entries are written from the perspective of someone who downloads and runs the distributed
binaries. They are generated by codex during `pnpm release` and reviewed before committing —
see the "Publish a release" section in the README.

## [Unreleased]

## [0.0.1] - 2026-06-02

### Added

- Added self-contained static binaries for Linux, macOS, and Windows on amd64 and arm64 hosts.
- Bundled universal-ctags with the Zoek binaries so symbol-aware indexing can run without installing ctags separately.
- Added checksum files for release assets so downloads can be verified before deployment.
- Added license and third-party notices for the distributed binaries.
